选一个会话名即可跨设备共享，默认保留 30 分钟，时长填 0 则永久。会话没有密码时，接口不要带 Authorization。有密码时，把密码原文放进 Authorization，不要写 Bearer。

curl 
把 HOST 换成这个网站的地址。没密码时不要加 Authorization。有密码时每条命令加上 -H "Authorization: 密码"，不要 Bearer。

curl -X POST HOST/api/sessions \
  -H "Content-Type: application/json" \
  -d '{"name":"weicopy","password":"","ttl_minutes":30}'

curl -X POST HOST/api/sessions/weicopy/items/text \
  -H "Content-Type: text/plain" \
  --data-binary "你好"

curl -X POST HOST/api/sessions/weicopy/items/file \
  -F "file=@/path/to/file"

curl HOST/api/sessions/weicopy/state

curl "HOST/api/sessions/weicopy/items/latest?raw=1"

curl -X PUT HOST/api/sessions/weicopy/items/ITEM_ID \
  -H "Content-Type: application/json" \
  -d '{"content":"新内容"}'

curl -X DELETE HOST/api/sessions/weicopy/items/ITEM_ID

curl -X DELETE HOST/api/sessions/weicopy
